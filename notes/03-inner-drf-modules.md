# Inner Drf Modules


## Json Response:

باید در فایل ویوز، فانکشنی ایجاد کنیم و مراحل زیر را انجام دهیم:
1. میتوان نوع رکوئست را در ورودی مشخص کنیم مثلا از نوع اچتی تی پی رکوئست هست
2. کوئری مد نظر را مینویسیم ولی تا زمانی که دستور را داخل یک حلقه قرار ندهیم یا به لیست تبدیل نکنیم، این دستور اجرا نمیشود
3. values: مشخص میکنیم که چه فیلد هایی میخواهیم واکشی شوند
4. آبجکت را در قالب یک دیکشنری میفرستیم به جیسان ریسپانس

```
def todos_json(request: HttpRequest):
    todos = list(Todo.objects.order_by('priority').all().values('title', 'is_done'))
    return JsonResponse({'todos': todos})
```

5. در فایل یوآرالز، مسیر را تغییر میدهیم
`path('', views.todos_json)`

6. وقتی مرورگر را باز کنیم، لیست آبجکت هارا در قالب جیسان مشاهده میکنیم

در این حالت ما سریالایز یا دیسریالایز را دستی انجام دادیم؛ در این حالت مشکل خاصی نیست
چون پروژه ی ما کوچک هست و در کل یک مدل بیشتر نداریم، اما اگر پروژه بزرگ شود
و مدل هایی رو داشته باشیم که با مدل های دیگر، رابطه های مختلفی داشته باشند
و ما اگر بخواهیم همه این هارا به همین روش پیاده سازی و مدیریت کنیم، واقعا توسعه پروژه سخت خواهد شد
به همین دلیل، مفهومی را داخل خود دی آر اف درنظر گرفتن به تحت عنوان سریالایزرها

بطور کلی داخل دی آر اف، یکسری کامپوننت داریم و اون کامپوننت ها در جریان رکوئست، ریسپاپس و
سریالایز کردن به ما کمک میکنند.

## DRF Components:

این ها را باید بالای فایل ویوز.پیوای اضافه کنیم تا بتوانیم از امکانات آنها استفاده کنیم:

1. from rest_framework.request import Request : قدرتمند تر و با امکانات بیشتر از اچتیتی پی رکوئست
2. from rest_framework.response import Response : قدرتمند تر و با امکانات بیشتر از اچتیتی پی ریسپانس
3. from rest_framework import status : داخل آن تمامی ریسپانس تایپ هایی که ما میتونیم ازشون استفاده کنیم وجود دارد
4. تا همینجا اگر اجرا بگیریم، در مرورگر خطا دریافت میکنیم، به همین دلیل باید برای فانکشن خود مشخص کنیم که یک
فانکشن بیس ویو در داخل دی آر اف هستش به همین دلیل باید ای پی آی ویو را ایمپورت کنیم
مابقی ویو هایی که میساختیم یک ویوی عادی بودند ولی ما میخواهیم ای پی آی ویو درست کنیم پس باید بصورت
دکوریتور برایش مشخص کنیم که یک ای پی آی ویو هست و داخل پرانتز برایش مشخص کنیم که متد یا درخواست از چه نوعی باید باشد.
5. from rest_framework.decorators import api_view : برای اینکه مشخص کنیم ویو از نوع ای پی آی هست

بنابراین با استفاده از کامپوننت های بالا که متعلق به دی آر اف هستند، فانکشن ما به این صورت تغییر میکند:


```
@api_view(['GET'])
def todos_json(request: Request):
    todos = list(Todo.objects.order_by('priority').all().values('title', 'is_done'))
    return Response({'todos': todos}, status.HTTP_200_OK)
```


`@api_view(['GET'])` : یعنی درخواست از نوع گت، میتواند در این فانکشن پردازش شود

الان که با مرورگر اجرا بگیریم، یک ظاهر به شدت جذاب رو میتوانیم از دی آر اف مشاهده کنیم و اگر از روی دکمه گت
فرمت رو روی جیسان قرار دهیم، آن فرمتی که نیاز داریم رو در قالب جیسان نشان میدهد
این دی آر اف این قدرت را دارد که با فرمت های مختلف دیتا را به ما نمایش بدهد

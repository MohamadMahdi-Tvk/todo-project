# GetById & Put & Delete

## GET:

در فانکشن مربوط به واکشی لیست و ایجاد لیست آیدی مدل ما دخیل نبود و نیازی بهش نداشتیم ولی در متد های ویرایش و حذف کردن و
گرفتن آیتم با آیدی، ما به آیدی مدل خود نیاز داریم، چون مثلا ما میخواهیم یک آیتمی حذف شود، باید کلیدی رو بهش بدیم تا
متوجه شود کدام آیتم باید حذف شود؛ پس باید براساس کلید اصلی از داخل دیتابیس واکشی شود و عملیات مورد نظر انجام شود پس از
این فانشکن بیس ویو که ابتدا ایجاد کرده ایم نمیتوانیم استفاده کنیم؛ پس باید یک فانکشن بیس ویو جدیدی ایجاد کنیم. در ورودی
که هم رکوئست را باید دریافت کنیم و هم آیدی مورد نظر و داخل فانکشن باید بریم و از دیتابیس آن آیتم را پیدا کنیم، آن را
داخل یک ترای اکسپت قرار میدهیم، و زمانی که دیتای ما وجود نداشته باشد اکسپشن دازنات اگزیست باید انجام شود:

```
@api_view(['GET', 'PUT', 'DELETE'])
def todo_detail_view(request: Request, todo_id: int):
    try:
        todo = Todo.objects.get(pk=todo_id)
    except Todo.DoesNotExist:
        return Response(None, status.HTTP_404_NOT_FOUND)

    if request.method == 'GET':
        serializer = TodoSerializer(todo)
        return Response(serializer.data, status.HTTP_200_OK)

```

سپس در فایل یوآر الز هم باید آدرس را اضافه کنیم:

`path('<int:todo_id>', views.todo_detail_view)`

حالا مثلا اگر در مرورگر بخواهیم بدانیم آیدی دو را پیدا کنیم:
http://127.0.0.1:8000/todos/2

## PUT:

در اینجا در قسمت سریالایزر دوتا آیتم باید بهش پاس دهیم، یکی اینستنس هست و آن یکی دیتا؛ یعنی اگر به سریالایزر فقط اینستنس
رو پاس بدیم، فقط سریالایز میکند، اگر فقط دیتا را پاس بدیم، دیسریالایز میکند و اگر جفتش رو پاس بدیم میاد، میاد ورودی اول
رو داخل خود نگهداری میکند و دیتای ورودی دوم رو داخل دیتای ورودی اول قرار میدهد و اینجوری آپدیت انجام میشود؛ بنابراین
دیتای ورودی دوم دیسریالایز شده و تبدیل میشود به پراپرتی هایی که داخل مدل تعریف کردیم به آبجکت پایتون تبدیل میشود و میاد
ورودی اول که مدل اصلی هست رو آپدیت میکند و فقط کافیست بعدش چک کنیم که سریالایزر ایزولید هست یا خیر و اگر اوکی بود سیو
انجام شود:

```
elif request.method == 'PUT':
    serializer = TodoSerializer(todo, data=request.data)
        if serializer.is_valid():
            serializer.save()
            return Response(serializer.data, status.HTTP_202_ACCEPTED)
        return Response(None, status.HTTP_400_BAD_REQUEST)
```

و در خود مرورگر یا در پست من به این صورت دیتای جدید رو پاس میدهیم تا روی همان آیدی ویرایش انجام شود مثلا آپدیت روی آیتم
با آیدی شماره سه انجام شود؛ پس میریم به آدرس زیر که آیدی 3 رو پیدا کند:

http://127.0.0.1:8000/todos/3

و سپس در کادر مقادیر جدید رو بصورت جیسان نوشته و روی دکمه پوت یا سند کلیک میکنیم و آیدی هم حتما باید جزو فیلد ها باشد:

```
{
    "id": 3,
    "title": "new todo from post method edited",
    "content": "this is third todo edited",
    "priority": 0,
    "is_done": true
}
```

# Post

میتوانیم مشخص کنیم که فانکشن بیس ویوی ما هم در خواست از نوع گت را پشتیبانی کند و هم درخواست از نوع پست را بتواند
پشتیبانی کند، و در مورد حتما باید در دکوریتور ای پی آی ویو برایش نوع پست را هم مشخص کنیم؛ پس عملا ما میتوانیم داخل
فانشکن، بنا به نوع رکوئستی که ارسال شده تصمیم بگیریم که چه کاری را انجام دهیم؛ یعنی اگر درخواست از نوع گت بود، بیاد دیتا
را برگرداند و اگر نوع درخواست از نوع پست بود، بیاد دیتا را داخل دیتابیس ما ذخیره کند. دیتایی که داره ارسال میشود، باید
به ساختار مدل های ما در جنگو تبدیل شود؛ پس عملا یک جیسان میاد و باید تبدیلش کنیم به ساختاری که در پایتون وجود دارد، پس
باید فرآیند دیسریالایز انجام شود؛ به همین دلیل باید دوباره بریم سراغ کلاس تودوسریالایزری که ایجاد کرده بودیم. اگر نمای
کلاس را ببینیم، گزینه اینستنس و دیتا را مشاهده میکنیم؛ اینستنس برای سریالایز کردن استفاده میشود و دیتا برای دیسریالایز
کردن استفاده میشود.

## is_valid:

با این مورد میتونیم چک کنیم که اگر سریالایزر ما، توانست دیتا را به درستی دیسریالایز کند و دیتا معتبر یا ولید بودند این
ولید بودن اشاره میکند به این که داخل فایل مدل اصلی ما، فیلد هایی که کلاس مدل دارد و اعتبارسنجی هایی که برایشان درنظر
گرفته شده، رعایت شده باشد تا ایزولید مقدار ترو را برگرداند؛ و در نهایت سیو را قرار میدهیم تا دیتا در دیتابیس ذخیره شود:

```
@api_view(['GET', 'POST'])
def all_todos(request: Request):
    if request.method == 'GET':
        todos = Todo.objects.order_by('priority').all()
        todo_serializer = TodoSerializer(todos, many=True)
        return Response(todo_serializer.data, status.HTTP_200_OK)
    elif request.method == 'POST':
        serializer = TodoSerializer(data=request.data)
        if serializer.is_valid():
            serializer.save()
            return Response(serializer.data, status.HTTP_201_CREATED)
    return Response(None, status.HTTP_400_BAD_REQUEST)
```

میتوان از خود ابزار دی آر اف توسط مرورگر برای تست این ای پی آی استفاده کرد:
http://127.0.0.1:8000/todos/
یا اینکه به پست من رفته و آنجا همین آدرس رو قرار داده، متد را روی پست قرار داده و میتوانیم در قسمت بادی حالت ارسال
اطلاعات را روی راو قرار داده و گزینه را روی جیسان قرار داده و سپس در کادر دیتا را بصورت جیسان مینویسیم و روی دکمه ی سند
کلیک میکنیم تا اطلاعات ذخیره شود، به این صورت دیتا را داخل کادر پست من پاس میدهیم:

```
{
  "title": "Todo from postman",
  "content": "this is fourth todo",
  "priority": 3,
  "is_done": false
}
```

با این دستور در سریالایزر مشخص میکنیم که همه ی فیلد ها سریالایز یا دیسریالایز شوند.

میسازیم و با استفاده از نوع درخواست، دستورات خود را مینویسیم.

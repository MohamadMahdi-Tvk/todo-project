# Mixins

ما یکسری ای پی آی پیاده سازی کردیم که ساختار پیاده سازیشون یکسان هست؛ پس اگر ما بتوانیم سیستمی را طراحی کنیم که از طریق
مدل و سریالایزر موارد مربوط به فانشکن های ای پی آی رو پیاده سازی کنیم کد نویسی ما به شدت کاهش پیدا میکند؛ در اینجا پای
میکسین ها و ویوست ها وسط میاید؛ در پس زمینه آنها همین کلاس بیس ویو های ما پیاده سازی شده است، ولی ما دیگه خیلی از
دستورات تکراری رو دیگه نیاز نیست بنویسیم؛ مراحل ایجاد به این ترتیب است:

1. `from rest_framework import generics, mixins`
2. یک کلاس ایجاد میکنیم؛ داخل میکسین ها یکسری کلاس ها برای ما آماده شده است که با ارث بری کردن از این کلاس ها ما میتونیم
   خیلی از دستورات را که از قبل آماده شده اند را استفاده کنیم؛ یعنی یکی از قابلیت های عالی پایتون هست که ما میتونیم ارث
   بری چندگانه داشته باشیم؛ یعنی ارث بری از چند تا کلاس بصورت همزمان؛ پس میکسینز. را که بزنیم کلی کلاس آماده وجود دارد؛
   یعنی ما به 4 عمل اصلی کراد دسترسی کامل داریم. مثلا:
3. mixins.ListModelMixin: برای لیست ها یعنی همان گت آل
4. mixins.CreateModelMixin: برای ایجاد آیتم جدید
5. برای اینکه کلاس ما تبدیل به یک ای پی آی ویو شود، باید در ورودی بعدی از کلاس جنریکس ای پی آی ویو هم ارث بری کنیم
6. خودمان باید متد های گت و پست را بسازیم ولی بجای اینکه بیایم خودمان دستورات را بنویسیم، میگیم خودش برامون هندل کند
7. داخل این کلاس باید مشخص کنیم که کوئری ست که میخواهیم استفاده کنیم چه چیزی است؛ یعنی در اینجا میایم کوئری که لازم هست
   رو پاس میدهیم و دوم اینکه باید کلاس سریالایزر را برایش مشخص کنیم.
8. سپس باید به ازای درخواست هایی که داشتیم، یعنی گت و پست؛ باید متد های داخلی خود میکیسن ها را فراخوانی کنیم
9. کافیه فقط داخل فانکشن مثلا گت از داخل سلف، بیایم و لیست رو فراخوانی کرده و رکوئست رو بهش پاس بدیم
10. برای کریت کردن هم باید فانکشن پست را ایجاد کنیم و در ریترن از سلف، فانشکن کریت رو فراخوانی کنیم و رکوئست را بهش بدیم

```
class TodosListMixinApiView(mixins.ListModelMixin, mixins.CreateModelMixin, generics.GenericAPIView):
    queryset = Todo.objects.order_by('priority').all()
    serializer_class = TodoSerializer

    def get(self, request: Request):
        return self.list(request)

    def post(self, request: Request):
        return self.create(request)
```

11. آدرس را فایل یو آر الز اضافه میکنیم:
    `path('mixins/', views.TodosListMixinApiView.as_view())`

12. وقتی به آدرس برویم مشاهده میکنیم که علاوه بر نمایش لیست در قالب جیسان، خودش برامون یک فرم اچتی ام ال ساخته و میتونیم
    فیلد هایش را پر کنیم و همینطور میتونیم از طریق فرمت جیسان هم در راو دیتا آیتم ایجاد کنیم.
13. برای درخواست های دیگر مثل گت بای آیدی، پوت، دیلیت هم یک کلاس جدا میسازیم و عین بالا موارد مورد نیاز را پیاده سازی
    میکنیم؛ و ارث بری های کلاس فرق میکند؛ یعنی ریتریو مدل میکسین برای گت بای آیدی، آپدیت مدل میکسینز برای آپدیت کردن، و
    دیستروی مدل میکسین برای حذف آیتم هستند، و سپس فانکشن ها را داخل کلاس ایجاد میکنیم:

```
class TodosDetailMixinApiView(mixins.RetrieveModelMixin, mixins.UpdateModelMixin, mixins.DestroyModelMixin, generics.GenericAPIView):
    queryset = Todo.objects.order_by('priority').all()
    serializer_class = TodoSerializer

    def get(self, request: Request, pk):
        return self.retrieve(request, pk)

    def put(self, request: Request, pk):
        return self.update(request, pk)

    def delete(self, request: Request, pk):
        return self.destroy(request, pk)
```

14. آدرس آن:
    `path('mixins/<pk>', views.TodosDetailMixinApiView.as_view())`

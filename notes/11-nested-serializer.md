# Nested Serializer

ما تا الان یک مدل تودو داشتیم که یکسری فیلد های ساده داشت، اما اگر مدل هایی داشته باشیم که بایکدیگر رابطه دارند و
بخواهیم سریالایزری داشته باشیم که بتواند این روابط رو هم پشتیبانی کند، باید چه کارهایی انجام دهیم؟ برای این موارد ما
مفهوم نستد سریالایزر رو داریم. ما در پروژه کاری میکنیم که کلاس تودو با یوزر رابطه داشته باشد:

1. ایمپورت کلاس مدل یوزر برای استفاده در کلاس مدلز

`from django.contrib.auth import get_user_model`

2. ایجاد یک متغییر یوزر که داخلش اون مدل اصلی یوزر ریخته شود

`User = get_user_model()`

3. باید هر تودو به یک یوزر متصل شود پس به ادامه ی فیلد های کلاس مدل تودو، ریلیشن آنرا اضافه میکنیم

`user = models.ForeignKey(User, on_delete=models.CASCADE, related_name='todos')`

4. مایگریشن میزنیم تا در دیتابیس هم تغییرات ما اعمال شود

5. باید یک سریالایزر جدید برای یوزر در فایل سریالایزر ایجاد کنیم

```
from django.contrib.auth import get_user_model
User = get_user_model()

class UserSerializer(serializers.ModelSerializer):
    class Meta:
        model = User
        fields = '__all__'

```

6. حالا باید یک ویو ایجاد کنیم که لیست یوزر ها را بیاورد و هر یوزر لیست تودوهایش برایش سریالایز شود و به ما نشان داده
   شود

```
class UsersGenericApiView(generics.ListAPIView):
    queryset = User.objects.all()
    serializer_class = UserSerializer
```

7. مسیر را ایجاد میکنیم:

`path('users/', views.UsersGenericApiView.as_view())`

`http://127.0.0.1:8000/todos/users/`

8. اگر به مسیر برویم، همه اطلاعات کاربران را میبینیم، اما لیست تودو هایش را مشاهده نمیکنیم؛ باید از ریلیتد نیمی که در
   کلاس مدل تودو برای فیلد ریلیشن یوزر تعیین کرده ایم در سریالایزر خود استفاده کنیم؛ یعنی میگیم تودوز که داخل یوزر هست،
   باید از تودوسریالایزر برایش استفاده کنیم؛ و تعیین میکنیم که ریدآنلی ترو باشد و مقدار منی هم ترو درنظر میگیریم:

```
class UserSerializer(serializers.ModelSerializer):
    todos = TodoSerializer(read_only=True, many=True)

    class Meta:
        model = User
        fields = '__all__'
```

پس اگر کلاس مدلی با مدل دیگر رابطه داشت باید در فیلد مربوط به رابطه مشخص کنیم که از چه سریالایزر دیگری باید استفاده کند
و تا زمانی که مشخص نکنیم، خودش متوجه نمیشود و اون فیلد رابطه رو سریالایز نمیکند.
